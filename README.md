# 사용시간 관리 (ChildGuard) v1.1

폰에 설치된 앱을 골라 하루 사용 시간을 걸고, 시간이 끝나면 잠금 화면을 띄웁니다.

## APK 만들기

**GitHub Actions (PC 설치 불필요)**
1. GitHub에 새 저장소(Private 가능) 생성
2. `ChildGuard.zip`을 풀어서 안의 파일을 전부 업로드 (`.github` 폴더 포함 확인)
3. Actions 탭 → Build APK → Run workflow
4. 완료 후 Artifacts에서 `childguard-debug-apk` 다운로드

**Android Studio**
Open → ChildGuard 폴더 → Build → Build APK(s)

## 사용 순서

1. 부모 PIN 4자리 설정
2. 빨간 카드 3개(사용정보 접근, 다른 앱 위에 표시, 배터리 최적화 예외) 각각 "허용하기"
3. 오른쪽 아래 **앱 선택** → 폰에 깔린 앱 목록(오늘 많이 쓴 순)에서 앱 탭
4. 시간·분 조절 또는 15분/30분/1시간/1시간 30분/2시간 중 선택 → 저장
5. 메인 화면에서 **시간 제한 켜기** ON

메인 화면에는 제한 걸린 앱만 남은 시간과 함께 표시됩니다. 누르면 시간 수정·해제.

## 한계

- 아이가 설정에서 권한을 끄거나 앱을 지우면 풀립니다 (Device Admin 미적용)
- 상단 알림은 Android 정책상 숨길 수 없습니다
- 확인 주기 5초라, 시간 초과 후 최대 5초 지연
- 삼성 기기는 설정 → 배터리 → 백그라운드 사용 제한에서 이 앱을 "제한 없음"으로
